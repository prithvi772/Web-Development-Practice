📌 HTML, CSS & Bootstrap Practice Assignment

🔗 Live Demo: https://assignment05webdev.netlify.app

This project is a simple webpage created to practice Bootstrap grid layouts along with basic HTML and CSS.
It displays image galleries of popular Bollywood actors using responsive layout techniques.

✅ What I Practiced

HTML structure using containers, rows, and columns

Bootstrap grid system (container, row, col-*)

Responsive images using img-fluid

Nested rows and columns

Combining custom CSS with Bootstrap

index.html — main webpage

style.css — custom styles

Image assets used in the gallery
