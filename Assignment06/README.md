📌 HTML, CSS & Bootstrap Practice Assignment

🔗 Live Demo: https://assignment06webdev.netlify.app

This project is a simple travel-themed webpage created to practice Bootstrap layouts and components along with basic HTML and CSS.
It demonstrates a structured layout with navigation, image sections, and call-to-action elements.

✅ What I Practiced

Bootstrap grid system (container, row, col-*)

Navigation layout using Bootstrap buttons

Responsive images with img-fluid

Spacing, alignment, and borders using Bootstrap utilities

Combining custom CSS with Bootstrap

📂 Files Included

index.html — main webpage

style.css — custom styles

Image assets used in the travel sections
