📌 HTML, CSS & Bootstrap Practice Assignment

🔗 Live Demo: https://assignment04webdev.netlify.app

This project is a simple webpage built to practice Bootstrap fundamentals along with basic HTML and CSS.
It showcases a list of favorite movies using Bootstrap’s grid system and utility classes.

✅ What I Practiced

Structuring webpages using HTML

Using Bootstrap grid system (container, rows, columns)

Responsive images with img-fluid

Spacing and alignment using Bootstrap utility classes

Combining custom CSS with Bootstrap
